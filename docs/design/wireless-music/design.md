# 自建单工作台产品方案

本页保留产品结构和竞品设计参考。详细业务口径以 [无线音乐自建单PRD](<../../../../../PRD/【1120】无线音乐自建单 产品需求文档(PRD).md>) 和已通过业务评审的 [3011交互稿](http://localhost:3011/flowos/self-service) 为准。

## 定位与复用

同平台新增并列的自建单工作台，独立承接无线音乐运营商人工登记的新建、列表、处理、查询和导出。共享登录、租户、组织人员、导航、页签、字段、列表及附件等基础组件；业务记录、办理路由和统计范围独立，不接入原工单池、自动派单、SLA或通用咨询量。原普通无线音乐工单不按产品名称迁移。

## 当前产品结构

| 层级 | 方案 |
| --- | --- |
| 入口 | 自建单工作台与工单工作台并列；本模块直接新建及返回 |
| 列表 | 我的／全部，默认全部；状态快捷项、独立业务字段筛选、可配列、排序、分页与导出 |
| 新建 | 空白可保存草稿并分配编号；正式创建才计登记，创建必填业务号码 |
| 处理 | 顶部左产品与业务、右来源与时限，联系人并入来源；下方处理、履历、联系及附件 |
| 办理 | 处理人负责编辑和结案；仅处理人发起调剂，特定角色可跨组；多条预约提醒随处理责任移交 |
| 结案及退回 | 终态可修订，业务回复时间可改且留痕；本组班组长可退回已结案单，知晓通知不消已退回 |
| 配置 | 复用平台后台入口，按业务表单独立维护目录；停用项历史值可继续办理 |

旧业务系统数据不迁移，已有原型记录及旧编号保留。材料短信、上传页、真实电话录音、归属、文件和离线消息另行接入；质检和班组看板后续建设。
