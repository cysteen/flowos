# 自建单工作台验收走查

在 [3011 自建单工作台](http://127.0.0.1:3011/flowos/self-service) 使用同一浏览器和地址走完主链路，保留单号。主流程用张三：`13857985858`／`123`；调剂后通过顶栏“切换演示角色”切至班组长王组长，两人均属于无线音乐处理组。

## 主链路

| 顺序 | 操作 | 预期结果 |
| --- | --- | --- |
| 1. 独立入口 | 从个人门户点击左侧自建单工作台，再点新建工单 | 菜单与原工单工作台并列；直接打开本业务表单，进入 `/self-service/new`，无需在统一建单选表单 |
| 2. 工作台及新建布局 | 先查看工作台，再进入新建页查看顶部、页头和联络区 | 工作台贴顶页签、状态快捷项、工具栏、折叠筛选、列设置及分页与原工单工作台同风格；新建左来源时限、右完整产品号码，无旧三卡、客户档案或归属卡，尚无单号和建单信息 |
| 3. 最小登记 | 仅填演示业务号码，如 `13800000001`，创建并处理 | 生成 `IFLYZJ` 开头的独立单号，处理中、处理人为张三；进入 `/self-service/:ticketNo`，刷新可恢复 |
| 4. 保存及列表 | 填来源、产品、描述和处理结果并保存，返回自建单工作台 | 同一单内容保留，出现在“我的”和有权查看的“全部”列表中；业务订购时间可留空，缺业务线映射可手选 |
| 5. 提醒与调剂 | 设置5分钟后提醒，调剂给王组长 | 即时变更处理人，无接收确认；提醒保留原时间并改提醒王组长；张三业务内容只读 |
| 6. 接手与到期 | 切至王组长，打开同一单，切到平台其他页面等到期 | 王组长可编辑；跨页弹出提醒，点击打开本模块正确工单 |
| 7. 附件 | 两人分别补一份附件，再切回王组长 | 同组可上传，只能删除本人文件，已结案后规则相同 |
| 8. 结案 | 缺项时点结案，再补齐后重试，业务订购时间留空 | 缺项提示且不结案；补齐后同一单变为已结案，不可调剂，待提醒取消 |
| 9. 修订 | 点击修订记录，修改结果并保存，查看履历 | 保持已结案，原结案及回复时间不变，留存修改人时间及前后值 |
| 10. 独立查询导出 | 在全部分别按业务号码、工单编号、运营商、处理组／人、来源、渠道明细和模糊内容查询；加入产品、省份、问题分类等可选条件，切换创建／接入／回复时间并设置到秒的区间后导出 | 每项条件生效，时间按对应字段精确匹配；列表、计数、分页和明细一致，近三个月仍按创建时间限制导出 |
| 11. 原系统隔离 | 记住本单号码，打开原工单工作台和查询中心检索，再查看普通工单 | 自建单不混入原列表、搜索或咨询计数；原工作台新建不提供无线自建单表单，原普通工单正常办理 |

提醒必须在结案前走查，提前结案会正常取消尚未触发的提醒。“我的”只包含本人未结案单；已转交或已结案记录从“全部”按权限查询。

| 已有记录与链接 | 打开本浏览器此前已保存的登记单及旧详情链接，仍能查看原编号、附件、履历和提醒，并进入新模块 |

| 数据与权限 | 切换组外查看账号及租户，按权限只读或无权查看，不得修改、跨组调剂或串租户 |
