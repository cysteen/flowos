验收环境为功能分支 `feat/wireless-music-self-service` 的 [3011 工作台](http://127.0.0.1:3011/flowos/tickets)。走查全过程使用同一浏览器及地址，保留同一张工单的单号。

主流程先用张三（二线专员）：账号 `13857985858`，密码 `123`。调剂后从顶栏头像的“切换演示角色”切换为班组长王组长；两人均在无线音乐处理组内。

## 主链路：登记到结案

| 顺序 | 操作 | 验收点 |
| --- | --- | --- |
| 1. 平台入口 | 从现有工单返回左侧“工单工作台”，点击“新建工单”，选择业务表单“无线音乐运营商登记” | 共用统一建单页和平台导航，工单类型固定为咨询。也可先选“无线音乐自建单”保存视图再新建，表单应预选 |
| 2. 新建布局 | 查看顶部及右侧 | 顶部左为来源与时限编辑区，右为完整产品与业务号码编辑区；无旧三张速览卡、客户档案和处理归属卡；没有尚未产生的单号及建单时间 |
| 3. 最小登记 | 仅填一个演示业务号码，例如 `13800000001`，点击“创建并处理” | 允许其他结案字段暂缺，生成正式单号，状态处理中，当前处理人张三；进入同平台工单详情，可刷新恢复 |
| 4. 保存补充 | 填来源、产品、问题描述和处理结果，点击保存；业务订购时间留空 | 继续更新同一单，产品带出已配置分类和业务线；缺少业务线映射可手选。无需关联客户。仅保存时不强制补齐结案字段 |
| 5. 提醒和调剂 | 先设置“5分钟后”提醒，再调剂给王组长 | 调剂立即生效，无接收确认；提醒原时间保留，接收人改为王组长；张三业务字段只读，但仍可按同组权限上传附件和调剂 |
| 6. 接手与提醒 | 顶栏切换为王组长，打开同一单；切到其他工单或工作台，等提醒到期 | 王组长可编辑，跨页面仍弹出提醒；点击可返回正确工单，通知记录有对应记录 |
| 7. 附件权限 | 王组长上传文件，再切回张三补一份文件 | 两人均可上传；每人只能删除自己上传的文件。完成后切回王组长继续办理 |
| 8. 结案校验 | 先在缺项时点击结案，再补齐页面标注的必填项后结案 | 缺项时不结案并定位错误；业务订购时间可为空；成功后保持同一单号，状态已结案，不再允许调剂，未触发提醒取消 |
| 9. 结案修订 | 点击“修订记录”，修改处理结果并保存修订，查看处理履历 | 状态保持已结案，原结案时间不变；记录修改人、时间和前后值，不重新生成工单或结案次数 |
| 10. 工作台和查询 | 返回工作台查看本组记录及已办；进入查询中心，选择该业务表单，用号码检索并导出明细 | 同一单在各入口数据一致，状态计数正确；来源、产品、创建或接入时间筛选有效；明确不计入通用咨询工单量 |

提醒验收应在结案前完成；若提前结案，尚未触发的提醒会正常取消。已办范围按当前操作人的办理记录取数，调剂前后人员可各自核对。
