# 自建单工作台评审与验证

评审范围为 `feat/wireless-music-self-service` 分支的独立自建单工作台、PRD和技术设计。本模块使用3011环境验收，具体操作顺序见 [验收走查](acceptance.md)。

## 评审关注点

| 范围 | 检查要求 |
| --- | --- |
| 平台入口 | 同平台并列菜单，新建和处理路由独立，页签及侧栏高亮准确 |
| 数据边界 | 登记动作不写原 `TICKETS`，原工作台、查询及咨询计数不混入登记记录 |
| 记录保留 | 缓存键、编号、附件、履历及提醒保留，旧业务链接兼容至新域 |
| 通用业务 | 原普通工单和400流程中的普通无线音乐工单正常，不能按产品名称误删或迁移 |
| 权限状态 | 组内调剂、处理人编辑及结案、组内附件补充、本人删除、组外只读按规则执行 |
| 提醒 | 调剂保留时间变更接收人，结案取消待提醒，跨页打开本模块正确单据 |
| 修订 | 保持终态和原结案／回复时间，记录前后值，不重复计数 |
| 工作台交互 | 贴顶页签、快捷项、工具栏、折叠筛选、可选字段、列设置和分页与既有工作台同风格 |
| 查询导出 | 自有业务字段分别查询，创建／接入／回复时间到秒，独立记录、历史目录、权限及筛选共用口径 |
| 并发及租户 | 旧编辑版本拒绝覆盖，跨页同步，异步附件不串租户，配置修改版本有效 |

## 原有回归规则

阶段校验、保存、结案修订、转交提醒、附件、并发与目录历史值继续纳入自动回归。原先用于验证共享工单投影的用例需改为原工单集合不受登记动作影响；不得沿用旧投影结果证明本轮分离完成。

浏览器需验证独立菜单到新建、处理、返回列表及查询导出的完整路径，同时从原工作台和查询中心反查隔离结果。旧截图和独立HTML示意不作为本轮结果依据。

验证结论以本轮实际运行的检查和截图为准，不将此前共享工作台方案的通过记录直接计为本轮通过。真实权限、服务端事务、号码归属、文件服务、短信与上传页、录音和跨设备消息属于生产验收范围。

## 自动验证

在仓库根目录执行：

```powershell
npm run typecheck
npm run build
node docs/design/wireless-music/verification/source-check.cjs
node scripts/test-registration-list-query.mjs
```

最终完整类型检查、生产构建、源码回归39项及独立列表查询回归15项全部通过。用例加载实际源码并隔离浏览器存储、租户、操作人和普通工单样例，覆盖分阶段校验、调剂提醒、结案修订、附件、并发冲突、目录历史值、独立号段、旧记录保留、精确旧投影清理、独立查看权限及普通工单集合不受写入。查询回归覆盖分离的业务字段、模糊文本、组合条件、精确时间区间及创建／接入／回复时间语义，不依赖普通样例时钟。

## 独立审查记录

| 问题 | 复现及修正要求 |
| --- | --- |
| 旧查询链接落入我的，隐藏已结案／已转交记录 | 带关键词的旧查询链接兼容至新工作台时，应进入全部；原手动查询继续遵循用户当前列表范围。此项已在代码中修正 |
| 缓存详情同时弹出多个调剂窗口 | 独立浏览器复现3个调剂窗口后，已修复详情绑定自身单号、仅激活实例响应、停用关闭窗口。复测A→B→A调剂仅1个窗口，离开后无残留；确认调剂仅修改A，B处理人不变 |
| 移除可选筛选后仍存在隐藏条件 | 移除可选字段时同时清空对应查询值。独立浏览器验证选择省份后0条，移除该条件恢复2条且字段不再展示 |

## 浏览器与数据边界复核

| 场景 | 结果 |
| --- | --- |
| 新入口及正式创建 | 新菜单可见且高亮，仅业务号码可生成IFLYZJ独立单号并进入自建单详情 |
| 原工单隔离 | 登记前后普通TICKETS数量不变且无登记投影，原工作台无无线自建单入口，原查询中心搜索新业务号码无自建单结果 |
| 缓存保留 | 已有3条登记记录、附件及版本未被重建或改写，旧编号可继续使用 |
| 调剂与全局提醒 | 新处理人接手，未触发提醒保留原时间并转收件人；在原查询页面到期弹出，点击返回正确自建单路由 |
| 附件、结案及修订 | 上传成功，结案后保持终态，修订保留原结案及回复时间 |
| 多详情缓存 | 独立浏览器A/B交替打开后调剂窗口唯一，离开无残留，动作仅修改目标记录 |
| 可选筛选 | 增加省份并选择值后正确收敛，移除省份清空隐藏条件并恢复记录 |
| 组合查询及导出 | 错误业务号码或运营商返回0条；正确号码、单号、渠道、运营商、来源及处理人组合返回1条，CSV仅导出该匹配记录 |
| 列设置 | 实际隐藏、恢复及向上拖拽排序生效，列定义与原工单列表独立保存 |
| 主视口视觉 | 1330×901下贴顶页签、状态快捷项、折叠工具栏、筛选区、列设置、表格及分页完整；页面scrollWidth为1330，无整页横向溢出 |

本轮独立审查发现的问题已修复并复测，未遗留已确认的P1／P2阻断问题。最终源码的类型、构建、回归及主视口验证通过；新截图已覆盖 `screenshots/01-create.png` 至 `04-query.png`，PRD引用均为实际独立模块。
